# Gravação da UI — UGEE1000BR

O arquivo `deliverables/video/parametrix_ugee1000br_ui_walkthrough.mp4` é uma captura real da interface ParametrIX em Chromium visível, feita por X11/FFmpeg em 1920×1080 a 30 fps. O ponteiro foi gravado com `draw_mouse=1` e percorre a viewport CAD centralizada, os controles CAE/LCA, a área CAM/toolpath, os controles SCOOBIII/VUC e o painel compacto do harness Qwen 0.5B. O projeto persistente exibido na barra do harness é `UGEE1000BR — Aero Concepts — Rotor 1 MW a etanol`.

O manifesto reproduzível está em `deliverables/video/parametrix_ugee1000br_ui_walkthrough.manifest.json`. A captura é evidência de interação da UI e vínculo do projeto; não é certificação de segurança física, ensaio de turbomáquina, aprovação de aeronavegabilidade, metrologia, balanceamento, overspeed, END ou liberação para fabricação. Essas limitações permanecem registradas no README do projeto e nos gates de requisitos.
